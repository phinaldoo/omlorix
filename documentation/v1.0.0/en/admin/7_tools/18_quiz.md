# Quiz

**Quiz** lets a model create an interactive multiple-choice quiz inside a chat. It needs no separate provider beyond the chat model.

Complete the shared [Tool Rollout Checklist](0_tool_rollout.md), then verify the assessment limitations below.

## Enable and test

1. Select **Quiz** on each allowed model.
2. Create a short quiz, answer every option, restart it, and reopen the chat.

Quiz content persists with the chat, but attempts and scores are not a durable gradebook. Answers reach the user's browser, and there is no proctoring or tamper-resistant assessment. Do not use it for secure examinations, compliance certification, or high-stakes decisions.

The model can produce incorrect questions or answers. Require review against authoritative material for training or education use.
