# Memories

When Memory is active, Omlorix can include recent memories from the effective personal or project scope in model context. The **Memories** tool itself can save one concise new memory when automatic memory creation is enabled; it does not list existing memories.

Complete the shared [Tool Rollout Checklist](0_tool_rollout.md), then verify opt-out and deletion behavior below.

## Enable and test

1. Enable Memory for the intended groups and verify the user's own Memory settings.
2. Select **Memories** on a trusted model.
3. Confirm that an in-scope harmless memory is supplied in a new chat, then ask the model to save a different harmless memory and verify it in **Settings > Memory**.

Context inclusion and tool-based creation do not override group or user opt-outs. Users view, edit, and delete existing memories through **Settings > Memory**.

Do not encourage storage of passwords, authentication codes, health records, or other unnecessary sensitive data. Disabling the tool stops new tool calls but does not delete existing memories; use the Memory controls or account data controls for deletion.
