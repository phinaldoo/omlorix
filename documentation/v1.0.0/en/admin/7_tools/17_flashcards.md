# Flashcards

**Flashcards** lets a model create an interactive two-sided study deck inside a chat. It needs no separate provider beyond the chat model.

Complete the shared [Tool Rollout Checklist](0_tool_rollout.md), then verify the study interaction below.

## Enable and test

1. Select **Flashcards** on each allowed model.
2. Ask for a small deck, flip cards, restart the view, and reopen the chat.

Deck content persists with the chat, but review progress is not a durable spaced-repetition record. The feature is not a learning-management system or assessment record.

The model generates the questions and answers, so they can be incomplete or wrong. Users should verify important study material against authoritative sources. Disable the tool on models that do not follow its structure reliably.
