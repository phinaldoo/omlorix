# Feedback

**Admin Settings > Feedback** summarizes thumbs-up and thumbs-down ratings and optional comments submitted on assistant responses.

## Review Feedback

Choose a time period, then review **Total Feedback**, **Positive**, **Negative**, **Approval Rate**, **Unique Users**, the distribution and timeline charts, model-level results, and recent comments. Filters can narrow recent entries by model, reaction, and whether a comment is present.

Feedback is voluntary. Approval rate can be misleading when the sample is small or the user population, model mix, or workload changes. Compare it with request volume, errors, and a qualitative review before changing a model or policy. Do not use a rating alone for decisions about an individual user.

## Export or Delete

- **Export Feedback** downloads all recorded feedback, not only the currently selected period.
- Delete an individual entry when it is invalid or should no longer be retained.
- **Delete Feedback** permanently removes all feedback in the selected period.

Exports and comments can contain personal, confidential, or prompt-related information. Restrict access, store them only for an approved purpose, and delete downloaded copies on schedule.

Deleting feedback does not delete the related chat, model statistics, audit records, or copies already exported. Confirm the selected period and any preservation requirement before a bulk deletion.
