# Accessibility in Omlorix

Omlorix supports keyboard navigation, screen readers, theme choices, browser zoom, responsive layouts, and operating-system motion preferences. Generated, shared, and third-party content can have a different level of accessibility.

## Configure the interface

Use **Settings > Appearance** for Theme Mode, message color, and Font. Use **Settings > Chat** for Chat Full Width, visible navigation and metadata, Markdown rendering, and the send shortcut. Use your browser or operating system for zoom, contrast, captions, text size, and reduced motion.

## Keyboard and screen readers

Use Tab and Shift+Tab to move through controls, Enter or Space to activate them, arrow keys in lists and tabs, Home and End to jump within supported tab lists, and Escape to close the topmost dialog, menu, or sheet. On a narrow screen, controls can move into menus or tabbed panels without becoming unavailable.

Open [Keyboard Shortcuts](../3_user_settings/15_keyboard_shortcuts.md) for Omlorix-specific commands.

Navigate by headings, landmarks, labels, and status messages rather than visual position alone. After opening or closing a dialog, confirm where focus moved.

For a generated chart, image, slide, or interactive item, ask the model for descriptive text or a table equivalent, then verify that alternative yourself. For uploaded audio or video, provide captions or a transcript when sharing with others.

## Report a barrier

Report the page, browser, operating system, assistive technology, exact steps, expected result, and actual result. Include a redacted screenshot or recording when useful.

Remove conversations, credentials, tokens, personal information, and unrelated content before sending a report. Use [Help & Support](../../common/support.md) for the reporting route provided by your Omlorix site.
