# Install Omlorix as a Web App

Supported browsers can install Omlorix as an icon and app-style window. The installed web app is still the same Omlorix site, uses that site's permissions and account sessions, and normally requires a network connection.

## Install

- **iPhone or iPad Safari:** Share > **Add to Home Screen**.
- **macOS Safari:** File or Share > **Add to Dock**.
- **Chrome or Chromium:** use the address-bar install control or **Install page as app**.
- **Edge:** Apps > **Install this site as an app**.
- **Android Chrome:** menu > **Install app** or **Add to Home screen**.

The wording and location vary by browser version. If no install action appears, confirm you are using your organization's secure Omlorix address, then create a normal home-screen shortcut or bookmark instead. You may need to sign in again because the installed app can use separate browser storage.

## Security and removal

Install only from your organization's real Omlorix address. App windows can hide the address bar, so reject unexpected sign-in pages or look-alike sites.

Removing the app or icon does not delete your account or data and may not end its session or revoke browser permissions. Sign out first on a shared device; use **Settings > Security > Log Out All Devices** if the device is lost or exposed.

Use the browser or device's normal app-removal controls.
