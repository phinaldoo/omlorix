# Realtime Call

Realtime Call provides a live voice conversation with a compatible model. Availability depends on the model, browser, provider setup, group access, and your realtime allowance.

## Start and control a call

Open the chat where you want saved text to appear, choose the intended model or Agent, and select **Start call**. The call starts with the current project, model, Skill, or Agent instructions when supported. Allow microphone access and wait until it is listening before speaking.

Use **Mute microphone** when you want to stop sending audio, **Show live transcript** when you want to read the current exchange, and **End call** when finished. Speaking while the assistant responds can interrupt it. Omlorix may request that the screen stay awake, but the browser or device can release that request.

Do not assume that an existing chat’s earlier messages were loaded into the call. Restate essential context after the connection is ready.

## Text, files, and saved content

While connected, supported setups can accept typed messages and files. Prompts, Notes, selected passages, chat references, and connectors are not supported during a live call; they remain attached so you can send them after ending it.

Omlorix saves completed text turns and visible tool activity when possible, not the call audio. Review the saved transcript because speech can be missing, misheard, or incomplete. It is not an authoritative meeting record.

Voice, transcript text, and files may be processed by the selected provider. Follow your organization’s privacy rules before discussing personal or confidential information. Provider session limits or your realtime allowance can end a call.
