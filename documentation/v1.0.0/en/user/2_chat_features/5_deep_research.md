# Deep Research

Deep Research runs a longer, multi-step investigation and produces a source-backed report. It is available only when the selected model and your access allow it.

## Start a useful run

Choose a model that lists **Deep research**, then provide a self-contained brief with the question, decision to support, date range, jurisdiction, required or excluded sources, and desired report structure. Explain how uncertainty and conflicting evidence should be handled.

Ask for primary sources and citations close to the claims they support.

## Monitor, export, and verify

Open **View research** to follow **Activity**, **Report**, **Sources**, and **Files**. Use **Cancel research** when the question or supplied context is wrong. A completed report can be exported as **PDF** or **Markdown**, and generated files can be downloaded separately.

A PDF or Markdown report is a readable deliverable, not a restorable Deep Research archive. **Download Everything** embeds retained Deep Research run state, evidence, reports, and stored artifacts with its parent chat; account import restores them with that chat when the content passes destination limits. Incomplete source runs are restored as failed rather than resumed, and imported runs cannot continue the source provider session.

Long pauses can be normal. Avoid starting a duplicate run unless the first one has failed or been cancelled.

Before using the result, open important sources and verify dates, quotations, calculations, missing evidence, and whether the conclusion follows from the evidence. A completed quality check does not make the report automatically correct.

Research can share your brief and supplied context with multiple AI, search, website, and file-processing services. Use only information you are authorized to send. Longer runs can consume more time and usage than normal chat.
