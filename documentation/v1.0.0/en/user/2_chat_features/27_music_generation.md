# Music Generation

A compatible model can create a music file from a written brief. Availability, duration, reference support, and output format depend on the selected model and your usage allowance.

Describe the genre, mood, tempo, instruments, structure, production style, intended use, and preferred duration. For vocals, provide the exact lyrics and label sections such as verse and chorus. For instrumental output, say **instrumental, no vocals**.

When visual references are supported, attach only authorized images and explain which qualities should influence the music.

Generated music appears in the chat and **Workspace > Files**. Wait until processing finishes before downloading. Each result is a new file and can use more storage and provider allowance. Requested duration and structure are guidance, not guarantees.

Listen for unintended words, recognizable material, clipping, abrupt endings, and whether the result follows the brief. Confirm rights to lyrics, voices, and references, and avoid deceptive imitation or unauthorized likeness.
