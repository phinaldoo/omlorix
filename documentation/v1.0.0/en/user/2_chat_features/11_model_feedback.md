# Model Feedback and Ratings

When feedback is enabled for your account, use **Thumbs up** or **Thumbs down** on a saved assistant response.

Choose **Submit without comment** or **Add comment**. A useful comment describes an observable issue, such as a missed requirement, unsupported claim, incorrect calculation, or poor citation. Do not include secrets, personal information, or unrelated confidential content.

Submitting feedback again replaces your previous reaction and comment for that response. There is no separate user action to withdraw it, so replace an outdated comment with the correction you want reviewers to see.

Authorized administrators can review feedback for quality analysis. Feedback can remain separate from the chat and does not automatically change the response, model, or future routing. Send a correction in the chat as well when you need a better answer.
