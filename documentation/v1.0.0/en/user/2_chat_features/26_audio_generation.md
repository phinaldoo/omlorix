# Audio Generation

A compatible model can turn written text into a new spoken-audio file. Availability depends on the selected model and your usage allowance. Use **Read aloud** when you only need temporary playback of an existing response.

Provide the exact text, language, pronunciation guidance, tone, pace, emotion, and audience. Start with a short sample when names or specialist terms matter.

Generated audio appears in the chat and **Workspace > Files**. Wait until processing finishes before downloading. Each result is a new file and can use more storage and provider allowance. The available voice and file format depend on the service.

Compare the recording with the source text. Check pronunciation, missing words, pacing, volume, and unintended changes before use.

Do not create deceptive or unauthorized impersonations. Consider consent, likeness and voice rights, privacy, accessibility transcripts, copyright, and any required disclosure before publishing.

For spoken playback of an existing answer, use [Read Aloud](16_read_aloud.md). See also [Workspace Files](../10_workspace/6_files.md) and [Usage Limits](../3_user_settings/14_usage_limits.md).
