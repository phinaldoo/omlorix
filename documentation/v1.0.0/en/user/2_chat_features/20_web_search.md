# Web Search

A model with **Web search** can look for current public information and return source links. Availability depends on the selected model and your account.

State the question, as-of date, location or jurisdiction, preferred sources, and desired output. For example:

> As of today, compare these two policies using their official websites. Cite every material difference and label any inference.

Open important links and confirm that they support the surrounding claims. A citation identifies a source; it does not prove that the model interpreted it correctly or found all relevant evidence.

Search can also return image or file results when available. Supported YouTube links can open as embedded players in chat. Check the original publisher, date, context, and reuse rights before opening, downloading, or publishing any result.

Search queries and requested pages may be shared with search, website, and AI services. Never include passwords, private links, confidential text, or personal information unless the use is authorized. Public pages can also contain misleading or manipulative instructions, so prefer primary sources and compare independent evidence.
