# Thinking and Reasoning Effort

Some models offer a **Thinking** control for future requests. Its choices depend on the model and can include **Off**, **On**, **Auto**, a budget, or effort levels such as **Low**, **Medium**, and **High**.

Use less effort for routine drafting, extraction, or classification. Use more for difficult analysis, planning, calculations, comparisons, or multi-step tasks. More thinking can take longer and use more of your allowance without guaranteeing a better answer.

The message-box control and **Model Settings** stay aligned for the selected model. Changing it affects later requests and revisions, not existing responses; Split Screen keeps an independent value for each side.

A model can reason even when no control is shown. Any displayed thinking or summary may be shortened or omitted and is not proof that the final answer is correct.
