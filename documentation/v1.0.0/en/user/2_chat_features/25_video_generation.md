# Video Generation

A compatible model can create a short video from a description and, when supported, reference images. Availability, duration, format, and audio support depend on the selected model and your usage allowance.

## Create a video

Describe one clear scene: the subject, setting, action, shot, camera movement, lighting, style, pace, and orientation. A simple first request is easier to revise consistently.

If reference images are supported, attach only authorized images and explain how each should influence the result. Ask for focused revisions and repeat anything that must remain unchanged.

Generated videos appear in the chat and **Workspace > Files**. Wait until processing finishes before downloading. Each result is a new file and can use more storage and provider allowance.

## Review before use

Check motion, continuity, people, objects, logos, text, and factual details. Length, dimensions, sound, and quality depend on the available model; a prompt cannot guarantee them. An AI-generated video is not evidence that an event occurred.

Consider consent, likeness rights, copyright, trademarks, privacy, captions, and any required AI disclosure before publishing.
