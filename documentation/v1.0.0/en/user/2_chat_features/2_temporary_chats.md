# Temporary Chats

**Temporary chat** keeps a new conversation outside normal chat history unless you save it. Its exact retention behavior is shown in the banner and is set by your organization.

## Start and understand the mode

Turn on **Temporary chat** before the first message. To prefer it for new chats, enable **Always Use Temporary Chat** under Chat settings when available. Your organization can hide or restrict these controls.

Read the banner each time. It states whether the chat:

- is not stored on the server;
- is stored and removed after the displayed period; or
- is stored until it is manually deleted.

Temporary mode does not stop AI providers, search, connections, or tools from processing the information needed for a response.

## Save or leave

Select **Save Chat** to turn the current temporary conversation into a normal saved chat. Otherwise, leaving, reloading, or replacing it can permanently discard the conversation. Save it before moving it into a project, sharing it, or relying on it later.

Copy important content before leaving an unsaved temporary chat. Temporary mode is not anonymous and does not replace authorization, data-classification rules, or provider agreements.

**Download Everything** includes a Temporary Chat only if the server still retains its record. A chat configured for no server storage, or one already removed by its retention policy, cannot be recovered. Import preserves temporary status, so a retained Temporary Chat stays outside normal history instead of becoming a visible saved chat.
