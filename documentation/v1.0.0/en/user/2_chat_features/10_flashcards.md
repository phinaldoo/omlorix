# Flashcards

A model with the **Flashcards** tool can create an interactive deck of 1–40 text cards. Use it for vocabulary, definitions, formulas, interview preparation, or source-based recall—not as a scored assessment.

## Create a focused deck

Ask for **interactive flashcards** and specify the learner level, number of cards, direction, source, and exclusions. Prefer one idea per card.

> Create 18 interactive flashcards from the attached networking guide for beginners. Use one concise question and precise answer per card, add a hint or example where useful, and use only the guide.

Each card has a prompt and answer; it can also include a hint, example, or note. The model authors the content, so check it against the source before studying.

## Study the deck

Select the card or **Show answer**, compare your recall, then rate it:

| Rating | Effect |
| --- | --- |
| **Again** | Returns the card soon |
| **Hard** | Returns the card later |
| **Got it** | Counts the card as mastered |

**Queue**, **Mastered**, and **Reviews** summarize the current study session. A card can return more than once until you select **Got it**.

**Shuffle** changes the order and **Reverse** swaps prompts and answers. Changing either restarts the current session. **Study again** starts another attempt with the same deck.

Progress, ratings, and review history belong to the current displayed study session and are not a durable learning record. They reset when the chat or widget is reloaded. The assistant does not automatically receive your ratings; name difficult cards in a follow-up.

When a chat is shared, cards are reviewed as static fronts and backs rather than as your study session. Use [Interactive Quizzes](9_quizzes.md) when you want scored multiple-choice practice.
