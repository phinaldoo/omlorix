# Split Screen

Split Screen lets you work with two independent chats side by side while using one shared message box.

## Open and send

Open **Split Screen** from the chat header, or drag a saved chat into a panel when that action is offered. On a narrow screen, tabs replace the side-by-side layout while both chats remain open.

Choose **Left**, **Right**, or **Both** above the shared message box before sending. **Both** sends the same message and selected context to each panel independently. The panels do not see or compare each other’s answers.

Each panel keeps its own chat, model, settings, history, and scroll position. Drag a saved chat between sides when offered. Use the panel’s own controls for model selection, sharing, downloads, or temporary-chat actions.

## Before replacing or closing a panel

Save any temporary chat and stop unfinished work. Omlorix warns before an action would replace or close a panel. Closing one panel returns the other to the normal chat view.

Sending to **Both** can use two model allowances and send the same information to two different services. The same draft, attachments, `@` items, and chat references are prepared for both panels, so check both models and every context chip before sending sensitive information.
