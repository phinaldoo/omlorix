# Image Generation and Editing

A compatible model can create a raster image from a description or edit an image attached to the conversation. Availability depends on your model access and usage allowance. For an editable document, diagram, or data graphic, use Canvas or an Interactive Visualization.

## Create or edit an image

For a new image, describe the subject, composition, setting, lighting, colors, style, orientation, and intended use. Include exact words only when they are essential.

For an edit, attach the source image, identify the change precisely, and state what must remain unchanged. Choose a model that supports image input and editing, and keep the original file because every generated result is separate.

Ask for focused revisions. Each result is a new file and can use more storage and provider allowance.

## Save and review

Generated images appear in the chat and **Workspace > Files**. Check text, people, hands, objects, logos, dates, and factual details before use. An AI-generated image is not evidence that an event occurred.

Only process material you are authorized to use. Consider consent, likeness rights, copyright, trademarks, privacy, accessibility text, and any required AI disclosure before publishing.
