# Interactive Visualizations

An Interactive Visualization can provide an adjustable chart, comparison, simulator, map, or explorable explanation inside a response. Use Canvas when the result must be a durable editable file instead.

Ask explicitly for an **interactive visualization** and describe the decision or concept, source data, labels, units, controls, comparisons, and audience. Use its controls to explore scenarios, then verify important values against the original data.

A visualization can propose a follow-up message, request public external data, or offer a download. Omlorix asks for confirmation before these actions. Review the complete prepared message, external destination, requested data, and filename before allowing them.

Ask for labelled controls, keyboard access, sufficient contrast, and a text or table equivalent. Request a plain-text explanation if the visualization is difficult to use.

Interactivity may not survive a chat download or share. Record important conclusions in normal chat text, keep the source data separately, and export an accessible table when one is offered. The visualization and selected AI service receive the data you provide, so use only authorized information.

For durable editable content, see [Canvas](22_canvas.md). For a static picture, see [Image Generation](24_image_generation.md).
