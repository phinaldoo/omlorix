# File Attachments and References

Add a file or prior chat when the model needs information that is not already in the conversation. Attach only the smallest useful set of context.

## Choose a source

Open the attachment menu. Depending on your access and browser, it can include:

- **Upload files** for files on your device;
- **Quick screenshot** to choose a screen, window, or tab and attach one captured PNG image;
- **Add meeting** for an existing or recorded meeting;
- **Choose chats** to attach prior conversations as reference context;
- **Choose uploaded files** for existing Workspace files; and
- a connected cloud file source.

Wait for every upload or import to finish before sending. A screenshot can contain notifications, other tabs, account names, or private content, so inspect the attachment and crop or remove sensitive information before use.

Tell the model which file to use, what to do with it, and what must be preserved or ignored. Attaching a filename alone does not explain the task.

Support depends on the selected model, your access, and the file type. The model picker shows relevant input formats, and Omlorix warns when the current model cannot use an attachment. Choose another model or convert only the required content when necessary.

## Large pastes and chat references

When you paste a long block, **Large text pasted** offers **Paste as text** or **Attach as file**. Attaching it as a file keeps the message readable but still sends the content with the request. Review the displayed character, line, and file-size information before choosing.

**Choose chats** attaches selected saved conversations as context; it does not merge them into the current chat or give the referenced chats access to this one. You cannot attach the current chat, and there is a limit to how many chat references can be added. Remove a reference chip when it is no longer needed.

## Limits, storage, and privacy

File size, count, storage, and upload permissions can limit attachments; follow the smaller limit shown by Omlorix. Large documents or media take longer to process, and acceptance does not guarantee that a model can interpret every page, sheet, frame, or embedded object.

Removing an attachment or reference from the message box does not delete its source. A reused file can also remain after a chat is deleted. Delete an owned file separately under **Workspace > Files** when appropriate.

Files may be sent to the selected AI or tool service. Remove credentials, hidden comments, revision history, personal information, and unrelated confidential content before uploading.
