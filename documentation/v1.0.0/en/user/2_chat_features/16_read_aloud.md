# Assistant Read Aloud

**Read aloud** speaks the text of a completed, saved assistant response. It appears only when browser speech or an available speech service is ready.

Open the response actions, select **Read aloud**, and adjust **Speed** as needed. Select **Stop** to end playback. Starting speech for another response stops the current one; changing speed while playing restarts playback at the new speed.

Read aloud omits fenced code and does not speak separate thinking, tool activity, or interactive widgets. It is playback, not an audio export. Tables, links, and symbols can sound ambiguous, so use the visible response when exact formatting matters.

With browser speech, voice processing is controlled by your browser or device. When an external speech service is configured, the response text is sent to that service to generate audio. Use headphones when sensitive content could be overheard.
