# Canvas Sharing

**Share canvas** publishes a supported, saved Canvas file through a public link. Your organization can disable new links or require referenced-file approval.

## Create a link

Open the saved Canvas preview and select **Share canvas**. Choose a future expiration and optionally enable password protection. The current preview must be up to date before Omlorix can publish it.

Review the entire file and remove internal notes, credentials, personal information, hidden data, and content you are not authorized to distribute. Test the link in a private browser window.

## Referenced files and later edits

A Canvas can include other Workspace files. Files you own can be approved as part of your public link; a file owned by someone else requires that owner’s separate **Allow publicly** approval. Until all required approvals are complete, public access remains blocked.

The link shows the current saved Canvas content, so later edits can change what viewers see. Save the source and refresh its preview—especially a LaTeX PDF—after changing the document or referenced files.

## Manage links

Use **Active links** to copy, open, edit, or delete a link. Each link has its own password and expiration.

Deleting a link prevents future access but cannot recall copied text, screenshots, downloads, or other saved copies.
