# Chat Sharing

**Share chat** publishes a reviewed view of one saved conversation. Availability and allowed audiences depend on your organization.

## Create and review a link

Open **Share chat** and choose **Anyone with the link**, **Signed-in users only**, or **Invite specific users**, when offered. A link can also use **Password protection** and **Expiration**.

Under **Review published responses**, choose one saved answer for every regenerated response. Review static tool outputs such as Quiz questions and answers, Flashcard fronts and backs, and MCP App text before publishing.

Create the link or send invitations, then test the published view with the intended access conditions. A signed-in or invited view may require a separate test account rather than a private browser window.

## What viewers receive

The shared view contains the published chat title, messages, selected answer versions, and supported static output or file references. It does not expose your bookmarks or unrelated Workspace content, and viewers cannot edit the original chat.

The link follows the current saved chat, so later turns can appear automatically. For a new turn with regenerated answers, Omlorix publishes its original answer until you choose another saved version. New static tool output remains hidden until you approve it. Reopen the share settings whenever the source chat changes.

## Manage access

Use the link’s **Open**, **Edit**, or **Delete** actions to test or change access. Review invitations and active links under [Shared Items](../6_privacy_data/3_shared_items.md). Send a password through a separate channel and set an expiration when access should end automatically.

A deleted or expired link blocks future access but cannot recall content already viewed, copied, downloaded, or captured. Treat every share URL as sensitive.

For a fixed private copy, use [Download Chats](../4_chat_conversations/6_download_chats.md) instead of a live share.
