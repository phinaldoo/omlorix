# AI Model Leaderboard

The leaderboard shows Artificial Analysis benchmark data for models that can be matched to models available to you in Omlorix. It appears only when enabled for your account.

Open **Select Model**, then choose **Don't know which model to choose? See here**.

## Read the table

The table can show **Intelligence Index**, **Coding Index**, **Agentic Index**, input and output formats, tools, and training-data information. Additional benchmark columns appear only when **Full data** is configured. Select **What do the benchmarks mean?** for descriptions.

Compare values only within the same benchmark and displayed data version. A blank value means the source did not provide a usable score. Some available models may be absent because their names or versions cannot be matched confidently to the benchmark catalogue.

Scores do not measure your exact instructions, files, tools, reliability, current latency, usage allowance, cost, or privacy requirements. Format and tool indicators also do not guarantee that every account or model configuration can use them.

Use the table to shortlist a few candidates, then test each with the same representative request and verify the output.
