# Understanding AI Models

Models differ in quality, speed, accepted inputs, generated outputs, tools, connections, reasoning controls, usage, and privacy terms. A familiar name does not guarantee the same configuration or provider in every Omlorix site.

## Match the model to the task

Check whether a model supports the inputs and outputs you need, such as text, documents, images, audio, or video. Also check its available tools and connections.

Your request can include relevant chat history and selected files, Skills, Prompts, Notes, Memories, project context, Agent instructions, connections, and tool results. Attach only what the task needs: unnecessary context can slow the answer, create conflicts, use more allowance, or expose extra information.

For important work, compare models with the same representative prompt and source material. Consider output quality, reliability, response time, usage, and the provider’s privacy terms. Benchmarks help create a shortlist but do not replace testing.

Changing the model affects future messages and revisions. Omlorix warns when the new model cannot use an attachment or capability already present in the chat. Resolve that warning, or start a new chat when you need a clean comparison or different confidentiality boundary.

In a very long chat, a supported model can compact older context so the conversation can continue. Compaction can reduce detail even though the visible messages remain. Restate critical constraints, reattach authoritative sources, or start a focused new chat when exact earlier wording matters.
