# Model Settings

Model Settings contains optional controls for future requests and revisions made with the selected model. The fields, defaults, and valid values come from that model and can change when you switch models.

Enable **Show Model Settings** under **Settings > Chat**. Then open the chat header menu and select **Open Model Settings**.

Depending on the model, you can see controls for reasoning, maximum output, variation, structured output, custom instructions, tools, or connections. Some models have no adjustable settings. Change one setting at a time and test it on a representative request. More reasoning or a larger output can increase time and usage without guaranteeing a better answer.

A custom system instruction affects future requests. Clear it when the temporary purpose is finished; use a Prompt, Project, Skill, or Agent when reusable context belongs there instead.

When presets are available, save a named preset only after reviewing every visible value. A preset belongs to the relevant model; applying it replaces that model's visible settings for later requests. Delete obsolete presets and avoid confidential information in preset names or instructions.

Blank or reset values return control to the model's normal behavior. Split Screen keeps settings separately for each panel. Settings cannot add unsupported capabilities or override access and safety rules.
