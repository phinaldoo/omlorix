# Selecting a Model

Open **Select Model** in the chat header to browse the models and Agents available to your account.

Use search or the **In** and **Out** format filters. Entries appear under **Pinned Models**, **My Models**, or **Server Models**, depending on your access.

Before selecting, inspect the entry’s description, performance information, status, warnings, and details under **Formats**, **Tools**, and **Connections**. Names can be customized, so similar names do not guarantee identical capabilities or providers.

Select an entry and confirm that its name appears in the chat header. It will be used for future messages and revisions, not earlier answers. If the chat already has attachments, resolve any compatibility warning before sending.

Use **Pin model** for up to eight frequently used models, and reorder pinned entries when offered. Pins also provide quick access in the sidebar. **Unpin model** removes only the shortcut; pinning never grants access or keeps an unavailable model active.

If no suitable entry is available, clear all filters and search. Use **Manage models** to open personal model setup when **Bring Your Own Key** is allowed; otherwise contact your Omlorix support contact.

If you are unsure, use [AI Model Leaderboard](4_leaderboard.md) to create a shortlist, then test the candidates on the same representative task. For optional advanced controls, see [Model Settings](3_model_settings.md).
