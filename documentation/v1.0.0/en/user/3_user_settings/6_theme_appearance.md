# Appearance

Open **Settings > Appearance** to choose:

- **Theme Mode:** **System default** follows the browser or device theme; **Light** or **Dark** keeps the selected mode.
- **Your message color** changes the background color of your messages.
- **Font** changes the main interface typeface.

Changes apply immediately to this account. Some editors, code blocks, generated content, and embedded tools may use their own styling, and message color does not alter messages seen in exported or shared formats.

For additional readability and motion controls, use your browser or operating system settings. See [Accessibility](../8_experience/2_accessibility.md).
