# Usage Limits

Open **Settings > Usage Limits** to review Omlorix allowances currently applied to your account. The page is hidden when none apply.

## What the cards show

A card shows its name, daily, weekly, or monthly period, current usage, allowance, reset countdown, status, and the affected model requests or tokens, tool uses, Dictation minutes, or Realtime minutes.

Models or tools listed on the same card share that allowance. Switching between items on the same card does not create a new allowance.

## When a limit is reached

| Limit | What you can do |
| --- | --- |
| Model requests or tokens | Wait for reset or choose an available model outside that limit |
| Tool uses | Continue without the tool, use another available tool, or wait |
| Dictation mode | Type the message or wait for the minute allowance to reset |
| Realtime calls | Continue in text chat or wait for the minute allowance to reset |

The status changes as usage approaches or reaches the allowance. A reset countdown is informational and can change after a refresh. Provider billing, BYOK charges, and provider-side limits are separate from Omlorix Usage Limits.
