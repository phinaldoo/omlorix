# Chat Settings

Open **Settings > Chat** to change how chats look and how the message box behaves. These choices do not rewrite saved messages.

## Chat Experience

- **Show Message Navigation:** show the right-side message navigation rail.
- **Show Model Settings:** show the model-settings action in chat.
- **Show Assistant Message Metadata:** show generation information below assistant messages.
- **Render User Messages in Markdown** and **Render Assistant Messages in Markdown:** interpret Markdown instead of displaying it as plain text.
- **Use Ctrl+Enter to Send:** use `Ctrl`+`Enter` (`Cmd`+`Enter` on macOS) to send; Enter inserts a new line.
- **Always Use Temporary Chat:** start new conversations in temporary mode when your account allows it.

Turning off Markdown rendering affects presentation, not the stored message text. Temporary Chat follows the retention notice shown by Omlorix; see [Temporary Chats](../2_chat_features/2_temporary_chats.md).

## Customization

- **Personality** selects a response style or custom instruction. See [Chat Personality](9_chat_personality.md).
- **Chat Full Width** expands the conversation area.
- **Assistant Speech Speed** sets the default speed for read-aloud playback.
- **Sidebar Button Visibility** controls the **Create Chat**, **Search Chats**, **Workspace**, **Automations**, and **Projects** shortcuts. Hiding a shortcut does not disable the feature or delete its data; use **Commands and chat search** (`Cmd/Ctrl`+`K`) to open an available hidden destination.

Buttons for features unavailable to your account stay unavailable regardless of sidebar visibility. See [Keyboard Shortcuts](15_keyboard_shortcuts.md) for send and navigation keys.
