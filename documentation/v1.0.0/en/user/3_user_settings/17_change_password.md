# Change or Set Your Password

Use a unique password or passphrase that you do not reuse elsewhere.

## Change or add a password

Open **Settings > Security > Sign-in methods**, then select **Change Password** or **Set Password**.

For **Change Password**, enter the current password, new password, and confirmation. The new password must differ from the current one. **Set Password** is for an eligible social- or SSO-created account that does not yet have a local password; enter and confirm the new password after the recent-identity check.

Follow the password checklist shown in the dialog. A successful password set, change, required replacement, or email reset signs out every current session. It also invalidates other password-reset links, cancels a pending email change, clears one-time authentication actions, and sends a security notice when email delivery is available. Sign in again with the new password.

These controls can be unavailable for a temporary account, when your organization manages sign-in, or when password changes are disabled. Confirm the new password works and keep another sign-in method before disconnecting a provider.

## Required password change

If Omlorix requires a password replacement after sign-in, complete the displayed form before continuing. Do not reuse a temporary or administrator-provided password.

## Forgotten password

Use **Reset password** on the sign-in page when available and follow the time-limited email instructions. Otherwise, use another connected sign-in method or contact your Omlorix support contact. Request a new reset message if the first link has expired; do not reuse an older link.

Never send your current or new password through email, chat, screenshots, or support messages. Review [Passkeys](4_passkeys.md) and [Security](3_security_privacy.md) for additional protection.
