# Keyboard Shortcuts

Open **Settings > Help** for the current, context-aware shortcut list. The list shows only available actions and displays `Cmd` on macOS and `Ctrl` on Windows and Linux.

## Global shortcuts

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl`+`K` | Open or close **Commands and chat search** |
| `Shift`+`Cmd/Ctrl`+`,` | Open or close Settings |

**Commands and chat search** can start a chat, search or open chats, choose a model, upload or choose files, control an active response, open Workspace, Projects, or Automations, change the theme, and run other currently available actions. Use the arrow keys to move, Enter to open, and Escape to close.

## In chat

**Settings > Chat > Use Ctrl+Enter to Send** changes the composer:

| Preference | Send/queue | New line |
| --- | --- | --- |
| Off | `Enter` | `Shift`+`Enter` |
| On | `Ctrl`+`Enter` (`Cmd`+`Enter` on macOS) | `Enter` or `Shift`+`Enter` |

While a response is running, sending another draft can queue it. With an empty composer, pressing the configured send key twice quickly stops the response. Escape also stops the response when no open menu or dialog needs to close first. See [Message Queue](../2_chat_features/4_message_queue.md).

## Navigation

- Arrow keys move through command, search, model, and tab results; Enter selects the highlighted result.
- In Workspace tabs, arrow keys move between visible tabs, while Home and End jump to the first and last tab.
- Escape closes the topmost menu, dialog, or sheet before it affects the chat.

Editors, spreadsheets, presentations, and interactive content can use their own shortcuts while focused. If a global shortcut performs an editor action instead, move focus outside that content and try again. Your browser or operating system can reserve some key combinations.
