# Passkeys

Passkeys let you sign in with a device unlock, password manager, biometric check, PIN, or security key. A passkey is bound to the Omlorix address and account for which it was created and is resistant to look-alike sign-in pages.

## Add a passkey

Open **Settings > Security > Passkeys**, select **Set Up Passkey**, complete any recent-identity check, and finish the browser, password-manager, or security-key prompt. Omlorix derives the displayed device name from the browser information. Confirm that the passkey appears in the list before relying on it.

At sign-in, enter your email if requested and choose the saved passkey.

## Manage safely

Keep another usable sign-in method before removing a passkey, resetting a password manager, or disposing of a device. Removing a passkey requires recent identity verification and can send a security notice. Removing the final usable method is prevented when Omlorix can detect it, but an external provider can still become unavailable.

Removing a passkey in Omlorix may not remove the copy held by your device or password manager. Remove that copy separately when appropriate.

A passkey created for another account or Omlorix address will not work here. If setup is unavailable, use a supported browser and a secure Omlorix address. If you lose every sign-in method, contact your Omlorix support contact.
