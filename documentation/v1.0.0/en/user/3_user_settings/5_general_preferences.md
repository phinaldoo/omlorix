# General Preferences

Open **Settings > General** to set the language and regional context Omlorix uses:

- **Language** changes the interface language and automatically uses a right-to-left layout for Arabic.
- **Country** supplies regional context.
- **Time Zone** is used for Automations, reminders, and displayed local times.
- **Location** is your city or primary working location.

Choose the time zone that matches where you work, especially if your country spans several zones. For Location, use a city or region rather than a precise home address.

These choices affect future use; they do not rewrite earlier chats or change an Automation's already configured schedule. Whether a model may receive them is controlled by **Allow LLM to Access Personal Information** under [Security](3_security_privacy.md).
