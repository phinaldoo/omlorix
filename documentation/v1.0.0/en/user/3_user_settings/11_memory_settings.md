# Memory Settings

Open **Settings > Memory** to control whether saved memory is available to your account and chats:

- **Enable memory:** make saved memories and memory tools available to your account.
- **Include memories in chats:** allow relevant saved memories to be included as model context.
- **Auto-create memories:** allow the model to save durable facts on its own.

Turning a switch off does not delete existing memories. **Enable memory** must be on before the other memory behaviors can take effect. Review, edit, import, or delete saved entries under [Workspace Memories](../10_workspace/12_memories.md).

A model can overlook a memory or save something inaccurate. Keep memories short, stable, and non-sensitive; repeat critical requirements in your visible request.

Temporary Chat does not override these switches. Turn off **Include memories in chats** and **Auto-create memories** before a conversation that should neither use nor create memories; changing the switches does not remove memory content already sent in an earlier request.
