# Edit, Revise, and Branch

Use message actions to correct a request, create another answer version, remove content, or start an independent conversation path. Available actions can be restricted for your account.

## Edit your message

Select **Edit message** on one of your saved messages. Update its text or attachments, then save. When **Save & regenerate** is offered, it saves the edit and creates a new answer from that point. Editing an earlier request changes the conversation state, so later answers may no longer match it.

Deleting an assistant message removes that response. Deleting one of your messages uses **Delete message and below** and permanently removes that message and everything after it. Branch first when you may need the original path.

## Revise an answer

Open **Regenerate options** on the latest assistant answer when you want another version of the same turn. This action can consume another model or tool allowance.

Choose **Try Again**, **Add Details**, **More Concise**, or enter your own **Revision guidance**, then select **Apply**. The retry uses the model and Model Settings currently selected for the chat.

Choose **Edit previous message** from the revision menu when the request itself needs to change. Review both text and attachments before selecting **Save & regenerate**.

Use the version controls below the answer to move between saved alternatives. Display the intended version before copying, bookmarking, sharing, or continuing the chat.

## Branch instead of overwriting

Select **Branch chat from this message** on a saved assistant response to create a separate chat containing the conversation through that response. Continue in the new chat without changing the original. The branch keeps the source chat's project assignment but starts with fresh chat-level state such as sharing and bookmarks.

To copy the entire conversation instead, use **Duplicate** from the chat menu. See [Name, Pin, and Organize Chats](5_chat_title_generation.md).

Every regeneration or new branch response can still be wrong. Compare facts, sources, calculations, and compliance with your request.

See [Model Settings](../5_models/3_model_settings.md) and [Usage Limits](../3_user_settings/14_usage_limits.md).
