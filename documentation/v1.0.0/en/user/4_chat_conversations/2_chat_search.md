# Chat Search

Open **Search Chats** and enter a phrase from a saved chat's title or message text. You can also search from **Commands and chat search** (`Cmd/Ctrl`+`K`). Use a distinctive phrase when the result list is long.

Select a result to open the conversation. Depending on the result, its menu can also offer **Edit** or **Delete**; deleting from search removes the chat rather than only the result.

Search covers your active saved chats. Unsaved Temporary Chats, archived chats, and deleted chats are not included, and attached-file contents are not searched independently. A result can match text from a saved response version that is not currently displayed, so review the opened conversation and its version controls in context.

Use [Archived Chats](3_archived_chats.md) for archived conversations and [Workspace Files](../10_workspace/6_files.md) for files.
