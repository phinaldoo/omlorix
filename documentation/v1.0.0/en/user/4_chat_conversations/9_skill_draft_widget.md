# Skill Draft Widget

A model with the Skills tool can propose a new Skill as a reviewable draft in the chat. Nothing is added to Workspace until you select **Save to workspace**.

Open **New skill** and use **Edit source** and **Preview** to review the Name, Description, Instructions, Compatibility, License, and every file. Check the required Skill definition separately from the optional **Scripts**, **References**, and **Assets**.

Use **New file** to add an editable supporting file, or remove one before saving. A linked generated file is copied into the Skill when saved. Files do not run automatically. Remove secrets, personal information, unsafe instructions, unrelated files, and content you are not allowed to reuse.

Select **Save to workspace** only when the source and preview match your intent. Then review the saved Skill in Workspace before sensitive use.

Saving does not automatically select the Skill in future chats, attach it to an Agent, or share it with anyone. Use **Open workspace** to inspect and share the saved result.

See [Workspace Skills](../10_workspace/8_skills.md) and [Skills in Chats](7_skills.md).
