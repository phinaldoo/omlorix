# Chat Message Bookmarks

A bookmark marks one saved user or assistant message so you can find it again. It is private to your account and appears only when Bookmarks are enabled for you.

Open the message’s **More options** and select **Bookmark**. If an answer has several versions, display the exact version you want first.

Open **Workspace > Bookmarks** to browse, search, filter, or sort your bookmarks. Select a bookmark to return to the source chat and saved response version. Remove it from the message menu or bookmark card; removing a bookmark does not delete the message.

A bookmark is a marker, not a copy or access control. It is not shown in a shared transcript. Archiving normally preserves it, but deleting the source message or chat removes its useful source. Share the complete source chat only after reviewing all of it.
