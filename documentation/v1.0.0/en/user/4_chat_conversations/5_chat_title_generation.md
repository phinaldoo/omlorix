# Name, Pin, and Organize Chats

Omlorix creates a short title for a saved chat after its first request. If automatic title generation is unavailable, text from that request can be used instead. The title does not change the chat's content.

Review the title because it can be vague, inaccurate, or expose sensitive words in the sidebar, search, downloads, or shares.

## Use the chat menu

Open the chat's sidebar menu for the actions available to your account:

- **Edit:** change **Chat name**, then select **Save changes**. You can also double-click a sidebar title.
- **Pin chat** or **Unpin chat:** move the chat into or out of **Pinned**. Drag pinned chats to set their order.
- **Duplicate:** create a separate copy of the whole saved conversation. The original remains unchanged; the copy keeps the project assignment but starts with fresh sharing and other chat-level state.
- **Add to project:** choose a project, or **No project** to remove the assignment. Project instructions and files apply to future requests after the move.
- **Archive:** move the chat out of the active list without deleting it.
- **Delete:** remove the chat under the retention rules shown in the confirmation.

Drag ordinary chat entries to change their order when that interaction is available. An **Unread assistant response** marker means a response finished while you were elsewhere; opening the chat marks it read.

Use [Edit, Revise, and Branch](1_regenerate_message.md) to copy only the conversation through a particular response. See also [Projects](../10_workspace/2_projects.md), [Archived Chats](3_archived_chats.md), and [Security](../3_user_settings/3_security_privacy.md).
