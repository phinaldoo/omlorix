# Skills in Chats

A Skill adds reusable instructions and optional Scripts, References, and Assets to a request. Skill access and authoring can be restricted separately.

Type `@`, open **Skills**, and select a Skill. Review its name, owner, description, instructions, and bundled resources in Workspace before using it with sensitive information. A **Managed Skill** is read-only for you.

A selected Skill can remain attached for later messages. Remove its chip when the task changes. Several Skills can conflict or consume too much context, so use only those needed for the request.

References and Assets provide context; a Script is still only part of the Skill until a capable tool or model uses it. Bundled resources do not grant extra permissions. A Live or Collaborate Skill can change after you add it, so treat unfamiliar instructions and files as untrusted before using powerful tools.

Using a Skill sends its relevant content to the selected AI service, including in Temporary Chat.
