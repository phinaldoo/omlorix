# Archived Chats

Archiving moves a saved chat out of the active list without deleting it. Use it for finished conversations you may need again.

Open the chat menu and select **Archive**. To find it later, open the profile menu and select **Archived Chats**, or choose **Archived Chats** from **Commands and chat search**. Select **Unarchive** to return it to the active list.

Archiving preserves the conversation and its project membership, bookmarks, and sharing. Existing share links can continue to work. Archive is therefore an organization tool, not a privacy or deletion control.

Use **Delete** only when you intend to remove the chat under the retention rules shown by Omlorix. Pinning and active-list ordering do not apply while a chat is archived. Files saved separately in Workspace may need separate deletion.
