# Download Chats

Open a saved chat's menu and choose **Download Chat as**, then select a format. In Split Screen, use the intended panel's own download menu.

| Format | Best for |
| --- | --- |
| TXT | Simple readable text |
| PDF | Printing or a fixed-layout copy |
| Word | Editing in a document application |
| Markdown | Portable formatted text |
| JSON | A detailed structured record |

JSON can contain more metadata, including embedded Subagent activity stored in assistant-message blocks, and is usually the most sensitive option. Readable formats can flatten or omit interactive widgets, tool activity, Subagent details, and alternative response versions. Attachments and generated files may be referenced rather than bundled, so download important Workspace files separately and test links before archiving the export.

Review every export before sharing it. It can contain personal information, filenames, citations, tool results, or content that was not obvious in the visible transcript.

Downloading does not create or revoke a share link, duplicate the chat in Omlorix, or delete it. The individual JSON download is not accepted by **Settings > Data Control > Import Account Data**, and Omlorix has no self-service single-chat restore action. Use the complete account archive for an Omlorix-to-Omlorix round trip. For details, see [Data Control](../6_privacy_data/2_data_controls.md). For a view that follows the saved chat, see [Chat Sharing](../2_chat_features/13_chat_share.md).
