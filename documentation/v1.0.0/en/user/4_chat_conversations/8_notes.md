# Notes in Chats

Attach a saved Note when the model needs reference material from Workspace. You can use owned Notes and accepted shared Notes that your account can open.

## Attach content

Type **@**, open **Notes**, and select a saved Note. Wait until the Note shows **Saved** before attaching it. Remove its chip when it is no longer relevant.

In Workspace Notes, select an exact passage and choose **Add reference**. Use a passage when the model needs only one part of a long Note. The selection appears as its own reference chip in the message box.

Add required Workspace files separately unless they also appear as attachments. A link written inside a Note does not by itself attach the file to the chat.

## Let a model edit Notes

A compatible Notes tool can list, create, view, or edit Notes within your access. It cannot edit a Live read-only Note or delete any Note. Use exact titles, request focused changes, and review the saved result in Workspace. Check **Version History** or download a copy before a major edit; delete an owned Note yourself from its Workspace options menu.

Note content may be sent to the selected AI service. Remove secrets and unrelated confidential information first.
