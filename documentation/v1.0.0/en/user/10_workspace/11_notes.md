# Notes

Workspace Notes are saved Markdown documents for writing, attached media, and reusable chat context.

## Write and add files

Select **Create Note** and start writing. Wait for **Saved** before leaving. Use the editor toolbar for formatting and links. Open the editor's **More actions** menu to add files or record audio; these commands are separate from the note item's options menu.

- **Add Files** creates attachment cards at the bottom of the note.
- **Insert Inline Media** places images or audio between paragraphs.
- **Record Audio** can capture a microphone recording or shared screen audio when the browser supports it.

Notes reference Workspace files rather than copying them into the note. Downloading the note does not bundle those files.

## Download and history

Download a note as **MD** or **PDF**. Referenced files are not bundled automatically.

**Version History** shows older changes and lets you compare **Changes** or **Preview** before **Restore**. Restoring a version replaces the current content and preserves the replaced content as another history entry. A Live read-only subscriber cannot open the owner's Version History.

## Share a Note

Open an owned Note's options and select **Share**. Choose **Clone**, **Live**, or **Collaborate**, then **Create a share link** or **Invite specific users**. Clone creates an independent copy, Live provides read-only synchronized updates, and Collaborate lets recipients edit the synchronized Note. Review **Active links** and delete a mode's link when it is no longer needed.

A shared Note can reference a Workspace file the recipient cannot access. If **File reference needs attention** appears, ask the owner to share its containing folder, choose **Replace file**, or **Remove reference**. Do not assume accepting a Note also grants access to every referenced file.

The Notes page does not provide a restorable Note-only import/export workflow or a move-to-workspace action. **MD** and **PDF** are readable downloads, not Note archives. Use the complete account archive under [Data Control](../6_privacy_data/2_data_controls.md) to move owned Notes and Version History between accounts. Self-service import skips an owned Note that already exists with the same source ID and does not restore Note share links, invitations, or subscriptions. Referenced files must also exist in the archive and import successfully.

Deleting an owned Note and its Version History is permanent and ends its synchronized shares. Removing a shared Note from your Workspace ends your subscription without deleting the owner's source.

Type `@` in chat to attach a Note. A compatible Notes tool can also list, view, create, or edit Notes, but it cannot delete them. Review every model-made change. To delete an owned Note, use its options menu in Workspace and confirm the deletion yourself.

Note use, model tools, and sharing can be controlled separately for your account.
