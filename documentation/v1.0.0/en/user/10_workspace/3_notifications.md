# Workspace Notifications

Open **Workspace > Notifications** to review share invitations, Automation results, system notices, and Canvas file requests. An unread indicator means the notification still needs review, not that its underlying action necessarily failed.

- For a share invitation, review the sender, item type, and **Clone**, **Live**, or **Collaborate** mode, then select **Accept** or **Dismiss**. Clone creates an independent copy; synchronized modes can change later.
- For a Canvas file request, select **Allow in Canvas**, **Allow publicly**, or **Reject** only after checking which file and Canvas are involved.
- For other notices, open the related item when available or remove the notification after reviewing it.

Accept items only from people you recognize. A synchronized item can change after you accept it.

Removing or dismissing a notification clears the inbox entry; it does not undo the event. For example, it does not delete an Automation chat, unsubscribe an already accepted item, revoke a share, or reverse Canvas access already granted. Manage the underlying item at its source or under **Settings > Shared Items**.

Workspace Notifications are instance-managed inbox records and are intentionally excluded from the complete account archive. Importing an archive does not recreate invitations, system notices, Automation notifications, or their read state. Review the restored source items and **Settings > Shared Items** instead.
