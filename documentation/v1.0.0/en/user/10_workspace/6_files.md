# Workspace Files

Open **Workspace > Files** to manage files you own or can access, including uploaded, imported, project, shared-folder, Canvas, presentation, Note, and generated files.

## Find and use files

- Select **Upload Files** or drop files onto the page when uploads are allowed.
- Search by name and use **All Files**, **Uncategorized**, or a folder to narrow the list. Sort and filters can vary with the current view.
- Select a file to preview it. Images, audio, video, HTML, Markdown, and PDFs can have specialized previews; unsupported or very large files fall back to **Download**. A preview can sanitize, render, or omit content, so use the original when completeness matters.
- Use an owned file's menu to rename, move, download, or delete it. Shared or project files can have fewer actions.
- In chat, choose an existing Workspace file from the attachment menu instead of uploading it again. When Omlorix recognizes a duplicate upload, it can reuse the existing file rather than create another copy.

**Storage limits** shows stored-file and storage usage. Imported files, generated media, Canvas output, and presentations can also use this storage. If uploads are disabled or a limit is reached, delete unneeded owned files or contact your Omlorix support contact.

## Deletion and privacy

Deleting an owned file is permanent. It can break references in chats, projects, Notes, Automations, Skills, Agents, Canvases, or shared folders. Download anything important and check dependent content first. Deleting a chat does not automatically delete separately stored files.

Before attaching a file, remove hidden, personal, confidential, or unauthorized information. The file can be sent to the selected model provider or a connected service.

**Download Everything** includes owned file metadata and bytes, including supported files used by Projects and other restored content. Account import recreates files under the destination account and remaps supported references, subject to destination file-type, upload, and storage limits. A normal **Upload Files** action imports only the selected file as new Workspace content; it does not restore archive relationships. Shared files you do not own and external cloud originals are not copied merely because you can access them.

Use [File Folders](7_file_folders.md) to organize and share groups of files.
