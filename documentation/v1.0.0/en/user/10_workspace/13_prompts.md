# Prompt Library

Prompts are reusable text templates that you attach to the message box when needed. They do not run, select a model, or add tools by themselves.

## Create and use

Select **Create Prompt** and enter **Title**, optional **Description**, and **Prompt content**. Keep placeholders and required inputs clear, and avoid secrets in every field.

To use one, type `@` in chat, choose **Prompts**, and select it. Review the resulting composer text, replace placeholders, add task-specific information, and send. Selecting the Prompt again inserts it again.

Use **Mine** and **Shared** filters or search to find a Prompt. If a collaborator updates one while you edit it, compare **Your draft** with the latest saved version and choose **Copy my draft**, use the latest version, or **Save my draft as the next version**.

## Share

Select **Share Prompt**, then create links or invitations as:

- **Clone:** independent copy.
- **Live:** synchronized, read-only prompt.
- **Collaborate:** synchronized prompt that recipients can edit.

Inspect shared prompts before combining them with confidential data, files, or tools. A synchronized prompt can change after you add it to your library. Remove unused links and use Collaborate only with trusted editors.

Review active links and remove obsolete ones. Deleting an owned Prompt is permanent and ends its synchronized shares. Removing a shared Prompt from your library ends only your subscription; a Clone remains independent.

Prompt Library and Prompt sharing follow your group policy.

The Prompt Library has no direct Import or Export action. **Download Everything** includes Prompts you own and accepted shared-Prompt subscription records. Account import recreates owned Prompts privately with new local IDs and attempts a shared subscription only if its source still resolves. It does not recreate source share links or invitations. Review revision content and placeholders after import.
