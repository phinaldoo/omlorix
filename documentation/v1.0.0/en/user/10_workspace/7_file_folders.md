# File Folders

File folders organize owned Workspace Files and can share a group of files; they are not synchronized desktop or cloud folders.

Select **New Folder**, enter a **Folder name**, and choose an **Icon & Color**. Move an owned file from its menu or drag it into a folder when offered. **Uncategorized** contains files not assigned to a folder.

Deleting an owned folder moves its files to **Uncategorized** instead of deleting them.

## Share a folder

Open **Share Folder** and create a link or invite specific users. Available modes are:

- **Clone:** recipients get independent copies of the folder and files.
- **Live (View Only):** recipients see synchronized updates but cannot edit.
- **Collaborate:** recipients can view and edit the synchronized folder.

Review **Active Shares**, including the mode and subscribers, and stop links that are no longer needed. A link can be forwarded, and deleting a share does not remove an independent Clone or recall downloaded files.

Folders shared with you appear under **Shared with me**. Review the file list before accepting. **Unsubscribe** removes a synchronized folder from your Workspace without deleting the owner's source; a Clone is your independent copy.

Sharing availability follows your group policy. For publishing one supported Canvas file with link controls, see [Canvas Sharing](../2_chat_features/14_artifact_sharing.md).

The complete account archive recreates owned folders and attempts to restore an accepted shared-folder subscription only when its target folder or active source share can be resolved. Unresolved subscriptions are skipped with a warning. An ordinary owned folder can carry its supported share identifiers into the destination; a conflicting identifier is regenerated, while automatic system folders remain private. Review every imported folder under **Active Shares**, its file placement, and its subscribers instead of assuming access stayed the same. For a cross-instance move, revoke any carried link and create a new destination-specific link.
