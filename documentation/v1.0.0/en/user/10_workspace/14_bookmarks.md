# Message Bookmarks

**Workspace > Bookmarks** is the management view for private shortcuts you added from saved chat messages.

Add or remove a bookmark from the message's **More options** menu. In Workspace, use search, filters, and sorting to find the saved shortcut you need.

Select a bookmark to return to the original chat and response version. You can remove it from its card and, when available, start **Share chat** for the source conversation.

A bookmark does not copy or protect the message. It follows the original chat's access, retention, sharing, and deletion. If the source chat or message is removed, the bookmark can disappear.

Before sharing from a bookmark, review the complete chat and its published response versions—not only the bookmarked message. See [Chat Message Bookmarks](../4_chat_conversations/4_chat_bookmarks.md) for the add/remove behavior.

Bookmarks have no standalone Import or Export action. Their state is embedded in retained chat messages in **Download Everything** and returns when that chat imports successfully. A hidden temporary or shadow-deleted chat remains hidden after import, so its restored bookmark does not create a visible standalone record.
