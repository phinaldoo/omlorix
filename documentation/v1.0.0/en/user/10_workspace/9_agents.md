# Agents

An Agent combines a **Base model** with saved **Instructions**, one optional **Skill**, and **Reference files and images**. It appears alongside models but is a reusable setup, not a separate model.

## Create and use

Select **Create agent**, then choose an **Icon**, **Agent name**, and accessible **Base model**. Add clear **Instructions**, an optional **Skill**, and only the reference files needed for the Agent's purpose. Saved files are attached automatically to every request that uses the Agent, so avoid unrelated sensitive material.

Choose the Agent in **Select Model** or through `@` in chat. Its instructions, optional Skill, and files are layered on the Base model, but your current request and safety requirements still apply. Review the selected Agent before sending when names are similar.

If the Base model, Skill, or file becomes unavailable, edit the Agent and choose a replacement. Review shared or imported Agent instructions before using them with confidential data.

## Share

Create links or invite users with:

- **Clone:** an independent copy.
- **Live:** synchronized use without editing.
- **Collaborate:** synchronized use and editing.

Recipients must have access to the **Base model**. Omlorix blocks acceptance when they do not. A cloned Agent can omit a Skill the recipient cannot access and tells them when this happens, so verify the resulting Agent before use. Sharing an Agent does not automatically grant separate access to every referenced item.

Deleting an owned Agent removes it from your Workspace and ends its synchronized shares. Removing a shared Agent ends only your subscription. Existing chats and independent clones remain.

Use the Agent's **Link** or **Invite** tab to manage sharing. Agent creation, use, and sharing can each be unavailable to your account.

The Agent page has no direct Import or Export action. **Download Everything** includes Agents you own and their stored assets; account import recreates them and remaps an included owned Skill when possible. Destination model access and file availability still apply. Accepted shared-Agent subscriptions are included only as export records and are not restored, and source share links are removed. Review every imported Agent before selecting it.
