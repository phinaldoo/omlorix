# Workspace Overview

Workspace keeps reusable information, files, and tools separate from individual chats. Open **Workspace** from the sidebar or **Commands and chat search** (`Cmd/Ctrl`+`K`).

Available tabs can include:

- **Notifications:** invitations, automation results, and other account notices.
- **Connections:** external services, cloud file sources, and personal MCP servers.
- **Files:** uploaded, imported, and generated files and folders.
- **Skills:** reusable instructions with supporting resources.
- **Agents:** saved combinations of a model, instructions, a Skill, and reference files.
- **Todo:** task lists.
- **Notes:** saved documents, attachments, and recordings.
- **Memories:** short facts or preferences for future chats.
- **Prompts:** reusable prompt templates.
- **Bookmarks:** messages saved for later.

**Projects** is a separate sidebar destination for grouped chats, files, instructions, and optional shared project memory. **Automations** is also separate even though its runs can use Workspace context.

Your organization controls which features, creation actions, and sharing modes are available. In chat, type `@` to search supported Skills, Notes, Prompts, models, Agents, or Connectors for the next request. Use **Settings > Shared Items** to review existing shares across Workspace types. In an editor, wait for **Saved** and respond to any unsaved-change or version-conflict warning before navigating away.
