# Todo

Workspace Todo organizes personal or shared tasks into named lists.

## Lists and tasks

Create a list with a name, optional description, and Icon & Color. Add tasks directly from the list. A task can include Notes, Due date, All day, Priority, Tags, Status, Subtasks, Links, and Attachments.

Use the checkbox to complete a task and the bookmark action to add important tasks to **Marked**. Open **Task details** for every field.

Use search, filters, and sorting to focus the list. Switch between **List** and **Board**; in Board, tasks are grouped as **To do**, **Doing**, and **Done**. Reorder or move tasks when the current view offers it.

Deleting a task or list is permanent. Review the selected item before confirming.

## Share and use with chat

Open a list's options and select **Share**. Create a link or invitation as **Clone**, **Live**, or **Collaborate**. Clone is independent, Live is synchronized and read-only, and Collaborate allows synchronized changes. Review active links and share Collaborate only with trusted editors.

If a permission has just changed, reload Omlorix before checking the menu again. Removing a synchronized list ends only your subscription; deleting an owned list is permanent.

A compatible Todo tool can list or search tasks; create and edit lists or tasks; complete, reopen, mark, move, or reorder tasks; and apply bulk complete, reopen, move, or tag changes from chat. It cannot delete a task or list. Perform deletions yourself on the Todo page, state the exact list and task in chat, and review every model-made change—especially bulk actions.

## Portability and bulk changes

The Todo page does not provide list-level **Import** or **Export**, bulk selection, or a bulk action menu. A chat tool can perform several task changes, but those actions remain separate from the Todo page and need careful review. To move owned Todo lists and tasks between accounts, use the complete archive under [Data Control](../6_privacy_data/2_data_controls.md). Import recreates private copies with new local IDs; Todo links, invitations, and accepted shared-list subscriptions are not restored.

Todo use and Todo sharing can be controlled separately for your account.
