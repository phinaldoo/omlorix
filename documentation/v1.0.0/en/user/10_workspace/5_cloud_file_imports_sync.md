# Cloud File Imports

A connected cloud file source lets you browse external files from the chat attachment menu and import selected files into Omlorix.

1. Connect the source under [Workspace Connections](4_connections.md).
2. In chat, open the file menu and choose **Add from** the connected provider.
3. Select the files, verify their account and names, and choose **Import selected files**.

Imported files are new Workspace copies and count toward your storage. Later changes in either copy are not synchronized automatically. Disconnecting the source or losing access to the original does not remove copies already imported into Omlorix.

A folder, shortcut, unsupported format, oversized item, or file you can no longer access may be unavailable. The file picker can open in a separate provider window. Review each imported copy before attaching it to a model, and delete the Workspace copy when it is no longer needed.

See [Workspace Files](6_files.md).
