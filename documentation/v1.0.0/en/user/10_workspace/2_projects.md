# Projects

Projects group related chats, project files, shared instructions, and optional project memory. Open **Projects** from the sidebar or **Commands and chat search**.

## Create and work in a project

Select **Add** to open **Create a personal project**, then enter a **Project name**. Choose an icon and color, add a **System instruction** for every project chat, and optionally turn on **Use separate shared project memory**.

Open a project and use **Chats** or **Files** in its panel. Select **Start a new project chat**, open an existing project chat, or **Upload project file**. The selected model can use the project's System instruction and files in every project chat. Keep both current and appropriate for all members.

An existing chat can be added from its chat menu with **Add to project** or removed by choosing **No project**. The new project context applies to later requests; it does not rewrite earlier messages. Deleting a project removes its attachments and project context, but the chats remain outside the deleted project.

## Shared project memory

When the owner turns on **Use separate shared project memory**, every project member sees and manages the same project Memories for those chats. Project facts are added alongside each member's personal profile rather than replacing it. Select **Manage project memory** to review them. Store only durable information suitable for every current and future member.

## Share a project

The owner can use **Invite Users** or generate a **Link** with an optional **Password** and **Expires at** time. Anyone who joins becomes a project member and can view all project chats and files, so review the entire project before sharing.

Owners can remove members and remove the link. Members can **Leave** the project. Ending access cannot recall content someone already copied or downloaded.

Projects and project sharing can be disabled by your group policy.

## Portability

**Download Everything** includes Projects you own and can reconnect their included chats and files during account import. It does not export project memberships or shared project Memories, and imported Projects are private: the source link, password, expiration, and member access are not restored. After import, verify the Project's instructions and files, then recreate only the memberships, memory, and sharing that are still appropriate.
