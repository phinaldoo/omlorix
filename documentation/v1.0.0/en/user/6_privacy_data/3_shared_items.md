# Shared Items

Open **Settings > Shared Items** to review **Shared by me** and **Shared with me**. Search or filter by Chats, Canvases, Projects, Folders, Notes, Todos, Skills, Agents, or Prompts.

This page manages share records that already exist; it does not create a new share. Start from the source item's **Share**, **Share chat**, **Share canvas**, or **Share Folder** action. For a Note, open its menu and select **Share**. Each source can offer links, invitations, or both.

## Manage access

For items shared by you, available actions can open or copy a link, change supported link settings, rotate a project link, or **Unshare** it. Some source pages call this action **Delete** or stop sharing for one mode. Ending a link immediately blocks future use of that link, but it cannot remove copies already made by recipients.

For items shared with you, **Open** the item or **Remove** it from your workspace. Removing a shared item ends only your subscription; it does not delete the owner's source.

## Sharing modes

- **Clone** creates an independent copy.
- **Live** or **Live (View Only)** provides a synchronized, read-only view.
- **Collaborate** allows synchronized editing.
- **Link** provides the access described by that item's sharing dialog.

A recipient may be able to forward a link. Passwords and expiration reduce risk but cannot prevent screenshots, copies, or downloads.

Review active links, their mode, recipients, passwords, expiration, subscriber or access count, and last-accessed time when displayed. Revoke links that are no longer needed. A source item's owner controls the original; collaborators should avoid editing while ownership or access is uncertain.

If Omlorix warns that the inventory could not be fully loaded, refresh and check the source item's Share controls before assuming access has ended. A recently changed group policy can also require a full application reload before a source item's Share action appears.

Do not use an account archive as a complete sharing backup. Imported chats, Projects, Todo lists, Notes, Prompts, and Agents are private, but an owned Skill or ordinary folder can carry supported share identifiers. Some accepted Skill, Prompt, or folder subscriptions are attempted only when their source still resolves. Shared Agent subscriptions, Note and Todo sharing relationships, and project memberships are not restored. After an import or account move, use this page and every source item's Share controls to identify retained, regenerated, missing, or unwanted access explicitly. Revoke any carried Skill or folder link and create a new destination-specific link for a cross-instance move.
