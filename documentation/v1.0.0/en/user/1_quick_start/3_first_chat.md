# Your First Chat

Use a small, non-sensitive, text-only request to learn the basic workflow before adding files, tools, or reusable context.

## 1. Start and choose a model

Select **Create Chat**, then open **Select Model**. Choose an available text model and review its **Formats**, **Tools**, and **Connections**.

If the list looks empty, clear the search and format filters. If no model remains available, contact your Omlorix administrator.

## 2. Choose the chat mode

Leave **Temporary chat** off if you want a normal saved chat. Turn it on before the first message when you want the storage behavior described in the temporary-mode banner.

Temporary mode does not prevent the selected AI service or tools from processing your request. See [Temporary Chats](../2_chat_features/2_temporary_chats.md).

## 3. Send a clear request

Enter:

> Rewrite these notes as exactly three concise bullets for non-technical project sponsors. Keep the date unchanged, separate the confirmed decision from the open question, and invent no owner. Notes: Launch review is 18 September. The pilot is approved. We still need to decide who prepares the training guide.

Select **Send message**. While the response is running, use **Stop response** if necessary.

Check that the answer has exactly three bullets, preserves **18 September**, separates the decision from the question, and invents nobody. Treat the answer as a draft even when it sounds confident.

## 4. Continue and organize

Ask a focused follow-up:

> Make the bullets more direct. Keep every fact and constraint from my first request, and add a one-sentence heading.

A normal chat appears in the sidebar after its first message is accepted. Use its menu to **Edit**, **Pin chat**, **Duplicate**, **Archive**, add it to a project, or **Delete** it when those actions are available. You can also double-click the sidebar title to rename it. A temporary chat appears in normal history only after you select **Save Chat**.

Unsent text may be restored in the same browser, but drafts are not a backup and may not preserve every selected item. Save important unfinished work elsewhere.
