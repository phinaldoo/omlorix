# Get Started with Omlorix

Omlorix brings AI models, conversations, files, and optional tools into one workspace. Your organization controls which models, pages, tools, and sharing actions are available, so your screen may contain fewer choices than this guide.

## Start in five minutes

1. Open your organization’s Omlorix site and use one of the sign-in methods shown.
2. Review the welcome and privacy notices, if they appear.
3. Select **Create Chat**.
4. Open **Select Model** and choose an available model or Agent.
5. Enter a small, non-sensitive request and select **Send message**.
6. Check the answer, then ask a follow-up in the same chat.

If **Register** is available, follow the displayed verification, invitation, approval, and terms steps. Otherwise, ask your Omlorix contact for access.

## Main areas

| Area | Use it to |
| --- | --- |
| **Create Chat** | Start a conversation |
| **Select Model** | Compare and choose models or Agents |
| Message box | Write a request, attach files, and add available context with `@` |
| Conversation | Review responses, citations, tools, and generated files |
| Sidebar | Open chats and enabled shortcuts |
| **Workspace** | Manage reusable files, Skills, Agents, Notes, and connections |
| **Settings** | Manage your profile, security, appearance, chat, and data choices |

On smaller screens, menus or tabs may replace side-by-side panels and some Workspace sections may appear under **More**. Use **Commands and chat search** (`Cmd/Ctrl`+`K`) to reach available destinations quickly.

## Write a useful first request

State the goal, essential context, constraints, audience, and desired output. For example:

> Turn these notes into five bullets for non-technical sponsors. Preserve every date, separate confirmed decisions from open questions, and invent no owners.

Use only the files and optional features the task needs. Check the selected model’s **Formats**, **Tools**, and **Connections** before relying on them.

## Review before relying on an answer

AI responses can be incomplete or wrong. Verify important facts, calculations, citations, and decisions with authoritative sources and qualified people.

The selected AI and tool services may receive your request, relevant conversation history, and the context you add. Never enter passwords, private keys, access tokens, recovery codes, or information you are not authorized to share. **Temporary chat** changes Omlorix’s storage behavior, not which services process a request.
